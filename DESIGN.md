# Makkal Connect Design System

This design system defines the premium visual aesthetic, layout structure, color palette, and micro-interactions for the **Makkal Connect** web portal.

## 🎨 Color Palette

The colors represent the official TVK political/social movement brand guidelines, combined with clean, modern web accessibility tokens.

*   **Primary (TVK Maroon):** `#800020`
    *   *Usage:* Core headers, primary action buttons, key indicators, active tabs.
    *   *Vibe:* Premium authority, deep dignity, political strength, cultural heritage.
*   **Secondary/Accent (TVK Gold/Yellow):** `#ffcc00`
    *   *Usage:* Highlights, eligibility badges, hover states, warning icons, energetic dividers.
    *   *Vibe:* Optimism, financial empowerment, bright future, prosperity.
*   **Dark Neutral Background:** `#0a0005`
    *   *Usage:* Deep rich maroon-black for intro overlays, dialog backdrops, and footer panels.
*   **Light Neutral Background:** `#ffffff` (Base) & `#f8f9fa` (Shaded containers)
    *   *Usage:* Main layout panels, content cards, calculator backdrop.
*   **Borders & Dividers:** `#e9ecef` and `#ffcc00/30`

## ✍️ Typography

*   **Header Font Family:** `Outfit`, `Inter`, system-ui, sans-serif
    *   *Style:* Bold, extra-heavy (black), tracked-wide, uppercase, commanding presence.
*   **Body Font Family:** `Inter`, system-ui, sans-serif
    *   *Style:* High legibility, medium weight (500/600), clean spacing.
*   **Tamil Accent/Script:** High-contrast sub-captions in native script with clean font-smoothing.

## 📐 Shape & Geometry

*   **Container Border Radius:** `24px` (`3xl`) for hero cards, modal dialogs, and main dashboard blocks.
*   **Button & Input Radius:** `16px` (`2xl`) for intuitive tactile actions.
*   **Border Weights:** `2px` crisp border outlines instead of muddy drop shadows for a premium, clean card deck feel.

## ✨ Micro-Animations & Dynamic States

*   **Shimmering States:** Interactive buttons utilize a subtle gold-to-yellow gradient shimmer background sequence.
*   **Transitions:** Smooth `cubic-bezier(0.16, 1, 0.3, 1)` transitions for hover effects, scale transformations, and expandable details.
*   **Overlay Blurs:** Backdrop blur (`backdrop-blur-md`) applied to full-page dialogs to focus user attention.
